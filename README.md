# Aplicación de Formularios en Streamlit
Esta aplicación está diseñada para crear, gestionar y procesar formularios de manera sencilla utilizando Streamlit. Permite a los usuarios ingresar datos a través de formularios interactivos y visualizar los resultados en tiempo real.
## Características
- Creación de formularios personalizados.
- Validación de datos de entrada.
- Visualización de resultados en tiempo real.
- Soporte para múltiples tipos de campos (texto, números, fechas, opciones múltiples, etc.).
- Fácil integración con bases de datos y servicios externos.
## Requisitos
- Python 3.7 o superior
- Streamlit
- Pandas (opcional, para manejo de datos)
## Instalación
1. Clona este repositorio:
    ```bash
    git clone  https://github.com/XzRaulzX/Forms_correccion.git
    cd Forms_correccion
    ```
2. Crea un entorno virtual (opcional pero recomendado):
    ```bash
    python -m venv venv
    source venv/bin/activate  # En Windows usa `venv\Scripts\activate`
    ```
3. Instala las dependencias:
    ```bash
    pip install -r requirements.txt
    ```
## Uso
1. Ejecuta la aplicación Streamlit:
    ```bash
    streamlit run app.py
    ```
2. Abre tu navegador web y navega a `http://localhost:8501` para interactuar con la aplicación.
